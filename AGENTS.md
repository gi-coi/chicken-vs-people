## Project objectives

Identify European countries with more chickens than people.

Deliverables:
- a simple static HTML dashboard (in `dashboard/`)
- a Markdown file recording what was uncertain/unclear during the process (in `docs/uncertainties.md`)
- a GitHub repository containing the above (submitted as a link)

Scope to define (record decisions + uncertainties in the Markdown file):
- "European countries" — which set? (EU / Council of Europe / geographic Europe)
- "chickens" — all chickens, or a specific category?
- "people" — resident population?
- data source(s) and reference year for both counts

Method:
- document every data source as it's used — URL, publisher, access date, and what it provides (in `docs/sources.md`)
- fact-check data before trusting it — see the `fact-check-data` skill

## Default folder structure
```text
docs/              = the Obsidian folder (notes, research summaries, reports)
  uncertainties.md = (deliverable) what was uncertain/unclear during the process
  sources.md       = running log of every data source (URL, publisher, access date)
  agent-notes/     = the agent's own notes, comments, and written output
data/              = research data — datasets and files the agent collects during research
scripts/           = code (analysis, data cleaning, packaging)
  tests/           = pytest tests
dashboard/         = static web app (HTML/CSS/JS) — the live dashboard
  data/            = packaged JSON the frontend loads (generated by scripts/)
AGENTS.md
README.md
```

## Tech guidelines
- use `uv` as the package manager
- do the heavy lifting (cleaning, aggregation, formatting) in Python under `scripts/`; keep the dashboard's JavaScript to simple filtering/slicing
- propose commits at meaningful checkpoints (after each working phase); commit more often when the user asks
